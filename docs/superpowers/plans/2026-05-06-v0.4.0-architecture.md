# v0.4.0 Group A — Architecture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract a shared, transport-blind scan-session engine; refactor the ESC/I-2 scanner onto it; rewrite the ESC/I scanner onto it. Eliminates ~80 LOC of async-encode glue, the `getState()` TypeScript-narrowing workaround, five copies of the `ESC e + param + double-ACK` pattern, and the `recvBuffer` strategy divergence between the two scanners. Establishes a single `Graph<Ctx>` data structure + `SessionTransport` interface that lets a future ET-2750 (issue [#43](https://github.com/mtheuma/epson2paperless/issues/43)) land as a one-line factory swap.

**Architecture:** A new `src/scan-session.ts` module owns generic graph execution, IS-packet framing, recv-buffer accumulation, rolling-timeout management, page-flush barriers, and EXIF orientation injection. Each scanner becomes a thin (~30 LOC) orchestration shell that builds a transport factory, calls `runScanSession({ graph, initialCtx, transportFactory, … })`, and translates the engine's `Result` to the existing promise-rejection contract. Per-protocol logic lives in `src/esci2/graph.ts` and `src/esci/graph.ts` (graph builders + protocol-specific helpers).

**Tech Stack:** Node.js 24+ / TypeScript 6 / Vitest 4 / Zod 4 / sharp 0.34 / pdf-lib 1.17. No new runtime dependencies.

**Spec reference:** [`docs/superpowers/specs/2026-05-06-v0.4.0-architecture-design.md`](../specs/2026-05-06-v0.4.0-architecture-design.md). When in doubt about *why* a design choice was made, the spec is authoritative.

```ts
export type SessionTransportFactory = () => Promise<SessionTransport>;

export interface SessionTransport {
  write(buf: Buffer): boolean | void;
  /** Polite close after normal completion. */
  end(): void;
  /** Fail-fast destroy for error paths. */
  destroy(err?: Error): void;

  on(event: "data", cb: (chunk: Buffer) => void): this;
  on(event: "error", cb: (err: Error) => void): this;
  on(event: "close", cb: (hadError?: boolean) => void): this;
}

// =============================================================================
// Graph
// =============================================================================

export interface Graph<Ctx> {
  initial: string;
  states: Record<string, GraphState<Ctx>>;
  /** Per-scanner default rolling timeout, in ms. */
  timeoutMs: number;
  /**
   * Pre-state-dispatch abort handlers, keyed by IS packet type. Used for
   * protocol meta-events (e.g. ESC/I-2 0x9000). Returns Error to fail;
   * returns null to ignore.
   */
  globalAbortHandlers?: Record<
    number,
    (ctx: Ctx, packet: { type: number; payload: Buffer }) => Error | null
  >;
  /**
   * Pre-dispatch packet filter — returns true to discard. Used for the
   * "wait for body" empty-envelope pattern (ESC/I-2 empty 0xa000).
   */
  globalIgnoreFilter?: (packet: { type: number; payload: Buffer }) => boolean;
}

/** Single write spec — concrete bytes or a ctx-thunk resolved at dispatch time. */
export type SendSpec<Ctx> = Buffer | ((ctx: Ctx) => Buffer);

export type GraphState<Ctx> =
  | { kind: "static"; on: Record<number, StaticTransition<Ctx>> }
  | { kind: "decision"; decide: DecisionFn<Ctx> };

export interface StaticTransition<Ctx> {
  next: string;
  /**
   * Bytes to write when this transition fires. Single-value form for
   * one-shot commands; array form for back-to-back multi-write patterns
   * where wire ordering matters (e.g. legacy ESC e: opcode and parameter
   * packet sent back-to-back, host then waits for two ACKs — delaying
   * the parameter write changes wire order and breaks replay tests).
   * Engine writes are sequential in array order; thunks resolve against
   * current ctx at dispatch time.
   */
  send?: SendSpec<Ctx> | SendSpec<Ctx>[];
  /**
   * Payload validator. The graph's `on:` table is keyed by IS packet
   * *type*; for protocols that further validate a payload byte (notably
   * ESC/I: every passthru reply is a `0x2000` envelope whose payload
   * byte 0 carries the protocol-level ACK / NAK), the transition
   * specifies a validator. Engine semantics: packet type matches → run
   * `validate(payload)`; true → apply; false → fail the session with a
   * state-tagged error. Use `globalIgnoreFilter` for "discard this
   * packet quietly" semantics — `validate` is for hard protocol errors.
   */
  validate?: (payload: Buffer) => boolean;
  flushPage?: PageFlush;
}

export type DecisionFn<Ctx> = (
  ctx: Ctx,
  packet: { type: number; payload: Buffer },
) => TransitionResult;

export type TransitionResult =
  | { next: string; send?: Buffer | Buffer[]; flushPage?: PageFlush }
  | { error: Error };

export interface PageFlush {
  /** Returns finished JPEG bytes. */
  encode: () => Promise<Buffer>;
  side: "front" | "back";
}

// Builder (authoring-only)
// =============================================================================

export interface GraphBuilder<Ctx> {
  state(name: string, def: StateDef<Ctx>): this;
  /** Set the graph's global abort handlers (preempt state dispatch). */
  globalAbortHandlers(
    handlers: Record<
      number,
      (ctx: Ctx, packet: { type: number; payload: Buffer }) => Error | null
    >,
  ): this;
  /** Set the graph's pre-dispatch packet filter. */
  globalIgnoreFilter(filter: (packet: { type: number; payload: Buffer }) => boolean): this;
  build(): Graph<Ctx>;
}

export type StateDef<Ctx> =
  | { on: Record<number, StaticTransition<Ctx>> }
  | DecisionDef<Ctx>;

export interface DecisionDef<Ctx> {
  __decision: true;
  decide: DecisionFn<Ctx>;
}

export function createGraph<Ctx>(initial: string, timeoutMs: number): GraphBuilder<Ctx> {
  const states: Record<string, GraphState<Ctx>> = {};
  let abortHandlers: Graph<Ctx>["globalAbortHandlers"];
  let ignoreFilter: Graph<Ctx>["globalIgnoreFilter"];
  return {
    state(name, def) {
      if (name === "DONE") {
        throw new Error('"DONE" is reserved as the engine terminal state; do not define a g.state("DONE", ...)');
      }
      if (states[name]) throw new Error(`Duplicate state name: ${name}`);
      if ("__decision" in def) {
        states[name] = { kind: "decision", decide: def.decide };
      } else {
        states[name] = { kind: "static", on: def.on };
      }
      return this;
    },
    globalAbortHandlers(handlers) {
      abortHandlers = handlers;
      return this;
    },
    globalIgnoreFilter(filter) {
      ignoreFilter = filter;
      return this;
    },
    build() {
      if (!states[initial]) throw new Error(`Initial state '${initial}' not defined`);
      return Object.freeze({
        initial,
        states: Object.freeze(states),
        timeoutMs,
        globalAbortHandlers: abortHandlers,
        globalIgnoreFilter: ignoreFilter,
      });
    },
  };
}

export function decision<Ctx>(decide: DecisionFn<Ctx>): DecisionDef<Ctx> {
  return { __decision: true, decide };
}
```

```ts
export async function runScanSession<Ctx>(
  opts: RunScanSessionOpts<Ctx>,
): Promise<RunScanSessionResult> {
  const { graph, initialCtx, transportFactory } = opts;
  const transport = await transportFactory();

  let ctx = { ...initialCtx };  // engine owns mutability
  let currentState = graph.initial;
  let errorReason: Error | null = null;

  const recvChunks: Buffer[] = [];
  let recvBytes = 0;

  return new Promise<RunScanSessionResult<Ctx>>((resolve) => {
    let settled = false;
    const settle = (result: RunScanSessionResult<Ctx>) => {
      if (settled) return;  // idempotent — close handler may also call this
      settled = true;
      try { transport.destroy(); } catch { /* swallow — destroy may throw on already-closed sockets */ }
      resolve(result);
    };

    transport.on("error", (err) => {
      errorReason = err;
      settle({ ok: false, reason: err, finalCtx: ctx });
    });

    transport.on("close", () => {
      if (settled) return;  // already settled — settle()'s destroy() emits close synchronously on fakes
      if (currentState === "DONE") {
        settle({ ok: true, finalCtx: ctx });
      } else {
        settle({ ok: false, reason: new Error(`Transport closed in state ${currentState}`), finalCtx: ctx });
      }
    });

    transport.on("data", (chunk: Buffer) => {
      recvChunks.push(chunk);
      recvBytes += chunk.length;
      // Fire-and-forget — `dispatching` reentrancy guard inside tryDispatch
      // ensures only one pump loop runs at a time; new chunks arriving while
      // the loop is awaiting just sit in recvChunks and get drained on the
      // next loop iteration.
      void tryDispatch();
    });

    /**
     * Resolves a transition `send` field — Buffer | function | array of
     * either — against the current ctx into a flat array of byte buffers
     * to write in order. Empty array means "no writes."
     */
    function resolveSend(
      send: SendSpec<Ctx> | SendSpec<Ctx>[] | Buffer | undefined,
    ): Buffer[] {
      if (!send) return [];
      const items = Array.isArray(send) ? send : [send];
      return items.map((s) => (typeof s === "function" ? s(ctx) : s));
    }

    /** Writes resolved bytes in order. */
    function writeAll(buffers: Buffer[]): void {
      for (const buf of buffers) transport.write(buf);
    }

    let dispatching = false;

    /**
     * Async pump loop. Reentrancy is prevented by the `dispatching` guard:
     * concurrent calls (from `'data'` events that fire while the loop is
     * awaiting an applyTransition) short-circuit; the active loop drains
     * any chunks they buffered on its next iteration.
     *
     * The loop checks `paused` at every step — set during a flushPage
     * barrier — and breaks out so multiple buffered packets in a single
     * TCP chunk don't dispatch concurrently with a flush.
     */
    async function tryDispatch(): Promise<void> {
      if (dispatching) return;
      dispatching = true;
      try {
        while (true) {
          if (paused) return;
          const packet = tryParseHead();
          if (!packet) return;
          await dispatchPacket(packet);
          if (paused) return;
        }
      } finally {
        dispatching = false;
      }
    }

    /**
     * Parse one IS packet at the head of recvChunks if a complete one is
     * present. Reads payloadSize directly from header bytes 6-9 (rather
     * than calling parseIsPacket on a partial buffer, which would return
     * null for any packet whose payload exceeds the peek window — that
     * was a bug in the previous draft of this plan).
     */
    function tryParseHead(): { type: number; payload: Buffer; totalSize: number } | null {
      if (recvBytes < IS_HEADER_SIZE) return null;

      // Ensure first chunk has at least IS_HEADER_SIZE bytes so we can read
      // the header fields without re-concatenating each time.
      if (recvChunks[0].length < IS_HEADER_SIZE) {
        const merged = Buffer.concat(recvChunks, recvBytes);
        recvChunks.length = 0;
        recvChunks.push(merged);
      }

      const head = recvChunks[0];
      // Validate magic
      if (head[0] !== 0x49 /* 'I' */ || head[1] !== 0x53 /* 'S' */) {
        settle({
          ok: false,
          reason: new Error(
            `Invalid IS magic at packet head: 0x${head[0]?.toString(16)} 0x${head[1]?.toString(16)}`,
          ),
          finalCtx: ctx,
        });
        return null;
      }
      const type = head.readUInt16BE(2);
      const payloadSize = head.readUInt32BE(6);
      const totalSize = IS_HEADER_SIZE + payloadSize;

      if (recvBytes < totalSize) return null;  // need more bytes

      // We have the full packet — materialize and peel
      const merged = recvChunks.length === 1 ? recvChunks[0] : Buffer.concat(recvChunks, recvBytes);
      recvChunks.length = 0;
      const payload = merged.subarray(IS_HEADER_SIZE, totalSize);
      const remainder = merged.subarray(totalSize);
      recvBytes = remainder.length;
      if (remainder.length > 0) recvChunks.push(remainder);
      return { type, payload, totalSize };
    }

    function dispatchPacket(packet: { type: number; payload: Buffer }) {
      // Stubbed for Task 12; implemented in Task 13.
    }

    // Kick off: enter the initial state. For now, just wait for first data.
  });
}
```

```ts
    async function dispatchPacket(packet: { type: number; payload: Buffer }): Promise<void> {
      // Step 1: globalIgnoreFilter — silently discard packets the protocol
      // wants to filter pre-dispatch (e.g. ESC/I-2 empty 0xa000 envelopes).
      if (graph.globalIgnoreFilter && graph.globalIgnoreFilter(packet)) {
        return;
      }

      // Step 2: globalAbortHandlers — protocol meta-events that preempt
      // state-specific dispatch (e.g. ESC/I-2 0x9000 fatal/cancel/info).
      // Returns Error → fail; null → continue (info-only event).
      const handler = graph.globalAbortHandlers?.[packet.type];
      if (handler) {
        const err = handler(ctx, packet);
        if (err) {
          errorReason = err;
          settle({ ok: false, reason: err, finalCtx: ctx });
          return;
        }
        return;  // null → handler consumed the packet, no state change
      }

      // Step 3: state-specific dispatch
      const state = graph.states[currentState];
      if (state.kind === "static") {
        const transition = state.on[packet.type];
        if (!transition) {
          // Fail-fast on unmatched packet types (parity with existing
          // ensure() pattern). Silent-ignore turns protocol violations
          // into eventual rolling-timeout firings with the wrong diagnostic.
          settle({
            ok: false,
            reason: new Error(
              `Unexpected packet type 0x${packet.type.toString(16).padStart(4, "0")} in state ${currentState}`,
            ),
            finalCtx: ctx,
          });
          return;
        }
        // Payload validation (e.g. ESC/I "0x06 ACK byte 0 inside a 0x2000 envelope")
        if (transition.validate && !transition.validate(packet.payload)) {
          settle({
            ok: false,
            reason: new Error(
              `Validation failed in state ${currentState} for packet type 0x${packet.type.toString(16).padStart(4, "0")}`,
            ),
            finalCtx: ctx,
          });
          return;
        }
        // Apply send (multi-write capable) + next (no flushPage handling yet; Task 16)
        writeAll(resolveSend(transition.send));
        currentState = transition.next;
        if (currentState === "DONE") {
          transport.end();  // triggers close → resolve ok in close handler
        }
      }
      // decision branch in Task 14
    }
```

```ts
  // globalIgnoreFilter / globalAbortHandlers checks run first (see Task 12);
  // omitted here for brevity but already in place.

  const state = graph.states[currentState];
  if (state.kind === "static") {
    const transition = state.on[packet.type];
    if (!transition) {
      settle({
        ok: false,
        reason: new Error(
          `Unexpected packet type 0x${packet.type.toString(16).padStart(4, "0")} in state ${currentState}`,
        ),
        finalCtx: ctx,
      });
      return;
    }
    if (transition.validate && !transition.validate(packet.payload)) {
      settle({
        ok: false,
        reason: new Error(
          `Validation failed in state ${currentState} for packet type 0x${packet.type.toString(16).padStart(4, "0")}`,
        ),
        finalCtx: ctx,
      });
      return;
    }
    await applyTransition(transition);
  } else {
    // decision
    const result = state.decide(ctx, packet);
    if ("error" in result) {
      errorReason = result.error;
      settle({ ok: false, reason: result.error, finalCtx: ctx });
      return;
    }
    await applyTransition(result);
  }
}

  writeAll(resolveSend(t.send));
  currentState = t.next;
  if (currentState === "DONE") {
    transport.end();
  }
  // flushPage handled in Task 16
```

### Task 14: Initial-state transport.write priming + the "first command sent on connect" pattern

**Files:**
- Modify: `src/scan-session.ts`
- Modify: `src/scan-session.test.ts`

**Why this exists:** today both scanners send their first byte (e.g. the lock packet) immediately after socket connect, *before* receiving any data. The graph model needs a way to express "the WELCOME state has no `on:` triggers — instead, on entering it, send X and transition to LOCKING."

There are two design options:
- (a) `WELCOME` state is decision-typed, fires when no packet is needed. But we'd need to invent a "no-packet trigger" event.
- (b) Initial transition runs once after `transportFactory` resolves: state machine starts with currentState = graph.initial, and the engine fires a synthetic "entered" event that looks for an `on: { 0: ... }` style "no-packet" transition.

Cleaner option: (c) — `Graph` supports an `onEnter?: (ctx) => Buffer | null` per state, fired when the engine *enters* the state and before it waits for the first packet. This composes naturally and is symmetrical for any state, not just initial.

Choosing (c). It's the natural fit for "send-then-await-reply" patterns that recur throughout both protocols.

```ts
async function applyTransition(t: TransitionResult & { next: string }) {
  if ("error" in t) return;  // already handled by caller

  if (t.flushPage) {
    // Stage next + send — neither is applied yet. The barrier order
    // (spec §3.5) is: stage → pause → encode/persist → unpause → write
    // staged send → enter staged next.
    const stagedNext = t.next;
    const stagedSend = t.send;

    paused = true;
    clearTimeoutTimer();  // suspend timeout during barrier (spec §3.6)

    pageIndex += 1;
    const myPageIndex = pageIndex;

    try {
      const jpegBytes = await t.flushPage.encode();

      // Track back-page index regardless of action (PDF mode needs it for
      // pdf-lib /Rotate=180 in finalizeSession)
      if (t.flushPage.side === "back") {
        backPageIndices.push(myPageIndex);
      }

      // EXIF action-gating (spec §3.5 step 5)
      let outputBytes = jpegBytes;
      if (t.flushPage.side === "back" && opts.action === "jpg") {
        const { setJpegOrientation } = await import("./exif.js");
        outputBytes = setJpegOrientation(jpegBytes, 3);
      }

      // Write to temp file
      if (!sessionTempDir) {
        sessionTempDir = await createSessionTempDir(opts.tempDir);
      }
      const filename = `page_${String(myPageIndex).padStart(2, "0")}.jpg`;
      await fs.promises.writeFile(path.join(sessionTempDir, filename), outputBytes);
    } catch (err) {
      const reason = err instanceof Error ? err : new Error(String(err));
      errorReason = reason;
      settle({ ok: false, reason, finalCtx: ctx });
      return;
    }

    paused = false;
    // Apply staged send (spec §3.5 step 8). Resolved via the shared helper —
    // a transition can have BOTH flushPage and a (ctx) => Buffer send, and
    // the function form must be resolved against ctx, not written as-is.
    writeAll(resolveSend(stagedSend));
    enterState(stagedNext);
    // Do NOT call tryDispatch() recursively here. The outer pump loop
    // (in tryDispatch()) is currently awaiting this very `applyTransition`
    // call — once we return, the loop's next iteration will pick up any
    // packets that arrived during the barrier and dispatch them with the
    // newly-entered state. Recursive dispatch would re-enter the
    // dispatching guard and short-circuit anyway.
    return;
  }

  // Non-flush path — uses writeAll(resolveSend(...)) for multi-write support.
  writeAll(resolveSend(t.send));
  enterState(t.next);
}
```

```ts
  // payloads abort the session regardless of state; ScanStart/Stop and
  // unknown bytes are info-only (return null to ignore). Mirrors
  // scanner.ts:345-387's existing handleAsyncEvent.
  .globalAbortHandlers({

      const dispatch = packet.payload.length > 0 ? packet.payload[0] : -1;
      if (ASYNC_FATAL_BYTES.has(dispatch)) {
        return new Error(`Async fatal event 0x${dispatch.toString(16)}`);
      }
      if (ASYNC_CANCEL_BYTES.has(dispatch)) {
        return new Error(`Async ScanCancel (0x${dispatch.toString(16)})`);
      }
      return null;  // ScanStart (0x01), Stop (0x04), or unknown — info-only
```

```ts
function statThenDrain(
  g: GraphBuilder<Esci2Ctx>,
  prefix: string,
  next: string,
): void {
  // STAT state: receive STAT reply (0x2000 envelope), parse declared length
  g.state(`${prefix}_STAT`, decision((ctx, packet) => {
    const declaredLen = parseDeclaredLength(packet.payload);  // see below
    if (declaredLen > 0) {
      return {
        next: `${prefix}_STAT_DRAIN`,
        send: buildPurereadPacket(declaredLen),
      };
    }
    return { next: `${prefix}_FIN`, send: buildPassthruPacket(buildFinCommand(), 64) };
  }));

  g.state(`${prefix}_STAT_DRAIN`, {
    on: { 0x2000: { next: `${prefix}_FIN`, send: buildPassthruPacket(buildFinCommand(), 64) } },
  });

  g.state(`${prefix}_FIN`, {
    on: { 0x2000: { next } },
  });
}

function parseDeclaredLength(payload: Buffer): number {
  // ESC/I-2 STAT reply: 64-byte envelope; declared length in bytes 8-11 (big-endian).
  // Verify against current scanner.ts which extracts this via parseEsci2ReplyHeader().
  const header = parseEsci2ReplyHeader(payload);
  return header.dataLength;
}
```

```ts
function makeTlsTransportFactory(
  session: ScanSession,
  socketFactory: TlsSocketFactory,

        port: session.port,

      socket.once("error", reject);
    });
}
```

### Task 31: Implement escEThenAck helper + early-init states

**The headline helper** — folds five copies of "ESC e + param + double-ACK" in current scanner-legacy.ts.

- [ ] **Step 1: Define the helper**

**Critical wire-ordering and packet-keying notes.**

- The graph's `on:` table is keyed by **IS packet type** (the outer envelope), not by the protocol-level ACK byte. ESC/I ACKs arrive as IS packets with type `0x2000` (passthru reply); the `0x06` ACK byte is in `payload[0]`. The transition uses `validate` to check the payload byte. Verify the IS type by reading `src/esci/scanner.ts`'s data handler — if it differs from `0x2000`, use whatever the existing scanner expects.
- Current `scanner-legacy.ts` sends the ESC e opcode and the parameter byte **back-to-back in the same tick**, then waits for two ACKs in sequence. The helper must NOT delay the parameter write until after the first ACK — that would change the wire write order and break replay tests. Instead, the **upstream transition** (the one that enters the helper's wait chain) emits both bytes via `send: SendSpec[]`. The helper only models the two ACK-wait states.

```ts
const ESCI_PASSTHRU_REPLY = 0x2000;  // Lift the actual constant from src/esci/commands.ts or scanner.ts.
const ESCI_ACK_BYTE = 0x06;

/**
 * Adds two ACK-wait states to the graph for the "ESC e + param then 2 ACKs"
 * pattern. Caller is responsible for the upstream transition that sends
 * both packets back-to-back via send: SendSpec[]. Example usage:
 *
 *     g.state("BEFORE_SOURCE", {
 *       on: { 0x2000: {
 *         validate: (p) => p[0] === ESCI_ACK_BYTE,
 *         send: [
 *           buildEscECommand(),                                 // opcode passthru
 *           (ctx) => buildParamBlock(SOURCE_BYTE[ctx.source]),  // param passthru
 *         ],
 *         next: "SOURCE_ACK1",
 *       } },
 *     });
 *     escEThenAck(g, "SOURCE", "STATUS_2");
 *
 * The helper just registers SOURCE_ACK1 and SOURCE_ACK2 as wait states.
 */
function escEThenAck<C>(
  g: GraphBuilder<C>,
  prefix: string,
  next: string,
): void {
  g.state(`${prefix}_ACK1`, {
    on: {
      [ESCI_PASSTHRU_REPLY]: {
        validate: (payload) => payload[0] === ESCI_ACK_BYTE,
        next: `${prefix}_ACK2`,
      },
    },
  });
  g.state(`${prefix}_ACK2`, {
    on: {
      [ESCI_PASSTHRU_REPLY]: {
        validate: (payload) => payload[0] === ESCI_ACK_BYTE,
        next,
      },
    },
  });
}
```

The validator's failure produces a state-tagged "Validation failed in state SOURCE_ACK1 for packet type 0x2000" error, which routes through the standard engine failure path.

**State-name convention.** With this shape, a typical "set source via ESC e" sequence in the graph reads as: an upstream state issues `send: [opcode, param]`, then `escEThenAck(g, "SOURCE", nextStateName)` registers `SOURCE_ACK1` → `SOURCE_ACK2` → `nextStateName`. Five copies of this pattern in `scanner-legacy.ts` collapse into five upstream `send: SendSpec[]` transitions plus five `escEThenAck(...)` calls. The state-count budget (≤14 hand-named) doesn't include helper-generated states like `*_ACK1` / `*_ACK2`.

```ts
// src/esci/scanner.ts

import net from "node:net";
import { runScanSession, type SessionTransportFactory, type SessionTransport } from "../scan-session.js";
import { resolveSessionTimestamp } from "../output.js";
import { esciGraph, type EsciCtx } from "./graph.js";
import type { Source, Format } from "./commands.js";
import type { PaperlessUploadOptions } from "../paperless-upload.js";

export interface LegacyScanSession {
  printerIp: string;
  port: number;
  outputDir: string;
  tempDir: string;
  duplex: boolean;
  forcedSource: Source | null;
  format: Format;
  jpegQuality: number;
  paperless?: PaperlessUploadOptions;
  onSourceDetected?: (source: Source) => void;
}

export type TcpSocketFactory = (host: string, port: number, onConnect?: () => void) => net.Socket;

function makeTcpTransportFactory(
  session: LegacyScanSession,
  socketFactory: TcpSocketFactory,
): SessionTransportFactory {
  return () =>
    new Promise((resolve, reject) => {
      const socket = socketFactory(session.printerIp, session.port, () => resolve(socket as SessionTransport));
      socket.once("error", reject);
    });
}

export async function runEsciScan(
  session: LegacyScanSession,
  socketFactory: TcpSocketFactory = (host, port, cb) => net.connect(port, host, cb),
): Promise<void> {
  const result = await runScanSession<EsciCtx>({
    graph: esciGraph,
    initialCtx: {
      duplex: session.duplex,
      forcedSource: session.forcedSource,
      source: session.forcedSource ?? "adf-simplex",  // safe default; overwritten in STATUS_2
      format: session.format,
      jpegQuality: session.jpegQuality,
      pageCount: 0,
      inInterPageLoop: false,
    },
    transportFactory: makeTcpTransportFactory(session, socketFactory),
    outputDir: session.outputDir,
    tempDir: session.tempDir,
    sessionTs: resolveSessionTimestamp(new Date(), session.outputDir),
    action: session.format === "pdf" ? "pdf" : "jpg",
    paperless: session.paperless,
  });
  if (!result.ok) throw result.reason;

  // The engine carries the final mutable ctx out via RunScanSessionResult
  // (see Task 11's RunScanSessionResult<Ctx> type). After STATUS_2's
  // decision-fn populated ctx.source, that value is preserved through to
  // here, regardless of how many transitions ran in between.
  if (session.onSourceDetected) {
    session.onSourceDetected(result.finalCtx.source);
  }
}
```

The `result.finalCtx` field is the post-run snapshot of the mutable ctx that was threaded through every transition. `STATUS_2`'s decision (Task 32) writes `ctx.source` from the FS F byte; the engine preserves that mutation through to the `{ ok: true, finalCtx }` return. Replay tests in `src/esci/scanner.test.ts` already use `onSourceDetected` to pin per-fixture detection — no test changes needed beyond the orchestration-shell wire-up here.

## Notes for the implementer

- **Replay tests are sacred.** Every milestone, the replay tests must stay byte-for-byte identical against existing fixtures. Drift = bug, not "test update." If a replay test fails after a code change, the code is wrong.
- **Each task ends with a commit.** Frequent commits are cheap; large rewrites that don't commit are expensive when something goes wrong.
- **TDD where it fits.** New code → write the test first. Mechanical edits (renames, imports) don't need TDD ceremony — just run the suite after each change.
- **The spec is authoritative.** When in doubt about *why*, read [`docs/superpowers/specs/2026-05-06-v0.4.0-architecture-design.md`](../specs/2026-05-06-v0.4.0-architecture-design.md). It explains every design decision.
- **Don't expand scope.** This plan covers M0–M3 only. If you find yourself wanting to fix something that isn't in the plan (e.g., the `KEEPALIVE_INTERVAL` not-wired-through bug, or `health.ts` binding to all interfaces) — note it in `.reference/next-steps.md` and move on. Those have homes in M5/M6.
- **CI runs on every PR to `dev`.** A green local run is a strong signal but CI is the gate. Don't merge a PR with red CI.
